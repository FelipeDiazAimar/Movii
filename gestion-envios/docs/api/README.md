# Documentación de la API

`openapi.yaml` es la especificación OpenAPI 3.0.3 de la API de Movii (`services/api`), generada a partir del código real de los handlers y structs de dominio.

Para visualizarla, pegá el contenido del archivo en https://editor.swagger.io, o abrilo con cualquier visor/editor de OpenAPI de tu preferencia.
